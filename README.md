Built using a supercharged MERN Stack and powered by Gemini 3 Flash, the platform transforms traditional resume builders into intelligent career optimization systems.

⚙️ Getting Started
📋 Prerequisites
Before running the project, ensure you have:
•	Node.js (v18+)
•	MongoDB Atlas Account
•	Vector Search Enabled
•	Gemini API Key
•	Stripe Account
________________________________________
📥 Installation
1️⃣ Clone Repository
git clone https://github.com/yourusername/elevatecv-studio.git

cd elevatecv-studio
________________________________________
🔧 Backend Setup
cd backend

npm install
Create a .env file inside /backend:
PORT=5001

MONGODB_URI=your_mongodb_uri

GEMINI_API_KEY=your_gemini_api_key

STRIPE_SECRET_KEY=your_stripe_key

STRIPE_PRO_PLAN_PRICE_ID=price_your_id

FRONTEND_URL=http://localhost:5173
________________________________________
🎨 Frontend Setup
cd ../frontend

npm install
Create a .env file inside /frontend:
VITE_APP_URL=http://localhost:5001
________________________________________
▶️ Run Development Environment
Start backend and frontend separately:
npm run dev
